# 전체 운영 오류 개선 계획

**목표:** 감사에서 재현된 CU 무좌표 재고 미조회와 위치 메타데이터 오류를 수정하고, 일시 원본 장애·올리브영 처리 대기의 사용자 실패를 줄입니다.

**설계:** CU 주소는 쉼표 뒤 건물 상세를 안전하게 제거하되 다른 숫자 주소가 섞인 경우 원문을 유지합니다. 실제 조회에 사용한 좌표를 REST/MCP에 반환하고 미확인 재고는 null로 보존합니다. CU 캐시 키를 올려 과거 잘못된 응답을 재사용하지 않습니다. 읽기 요청 재시도는 정상 인증·조회만 대상으로 원래 시간 예산 안에서 제한하며, 일일/분당 quota와 인증 오류는 재시도하지 않습니다. 매번 실제 재고 호출은 기존 중계 입구를 통과해 원장을 소비합니다. OY 동시 처리 제한은 유지하며 consumer-busy에만 짧게 기다려 같은 읽기를 다시 요청합니다. 외부 사이트가 계속 실패하면 정확한 오류·부분 결과를 유지합니다.

- [ ] OY: transport.ts에서 consumer-busy → 정상, 지속 busy의 총 시간/횟수 제한, daily/minute/consumer/auth/malformed 미재시도 회귀를 RED로 확인하고 한정된 재시도를 적용합니다. relay의 동시성·원장·인증은 그대로 유지합니다.
- [ ] EM/GS: 기존 재시도 범위와 시간이 누적되는 원인을 확인하고, EM 한정 public403/timeout 및 편의점 읽기502/503/504의 재시도를 같은 총 시간 안에 적용합니다. 안전한 작업 allowlist·응답 body 정리·실제 quota 소비·변경 없는 auth/quota 오류를 검증합니다.
