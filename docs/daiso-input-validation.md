# 다이소 조회 입력과 빈 페이지 처리

다이소 REST·MCP 조회는 외부 API를 호출하기 전에 입력을 검증합니다.

- `page`, `pageSize`, 매장 `limit`, 상품 후보 `productLimit`은 유한한 양의 정수입니다. 0·음수·소수·NaN·Infinity·숫자 뒤 문자를 거부합니다.
- 재고 좌표는 위도 -90~90, 경도 -180~180의 유한한 숫자 두 값을 함께 입력합니다. 둘 다 생략하면 기존 서울 시청 기본값을 사용합니다. 한쪽만 입력해 나머지를 기본값으로 채우지 않습니다.
- REST는 잘못된 입력에 HTTP 400/`INVALID_PARAMS`를 반환합니다. MCP는 입력 오류로 실패하며 재고 0으로 바꾸지 않습니다.
- 재고 검색어에 매장이 있으면 결과 범위를 벗어난 페이지는 빈 목록과 실제 전체 매장 수를 반환합니다. 빈 페이지라는 이유로 다른 검색어 변형에 넘어가지 않습니다. 검색 자체가 빈 경우의 검색어 보정은 유지합니다.

`keyword=강남`은 매장명·주소의 키워드 검색이며 강남구 행정 경계나 반경 필터를 의미하지 않습니다. `inStockCount`는 반환된 페이지의 재고 보유 매장 수입니다. `totalStores`는 검색된 전체 매장 수이며 서로 다른 범위의 수입니다.

다이소 상품/매장/재고 캐시는 v3로 변경해 이전 입력·페이지 오응답을 무효화했습니다. 상세·진열 위치 캐시 및 중계 인증·호출 예산은 변경하지 않습니다.

함께 수정한 메가박스 표시: 공식 상영 목록의 HTML entity를 극장·영화 이름에서 해석하며, 공식 지점 HTML의 도로명주소 li/span과 기존 dt/dd 형식을 읽습니다. 원본에 없는 주소는 빈 값으로 유지합니다. 관련 REST 캐시 v4로 이전 이름·주소 응답을 무효화하며 외부 서비스의 시간 초과 정책은 그대로입니다.
