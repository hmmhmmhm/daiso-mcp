# 무료 위치 검색

주소·역명·상호명은 카카오맵 주소/키워드 검색으로 좌표를 구합니다. 역명·상호명 검색은 네이버 지역 검색으로 보완합니다. REST, MCP, CLI의 기존 위치 입력을 유지하며 Google Geocoding과 Zyte는 호출하지 않습니다.

## 설정

로컬 환경 변수 또는 Cloudflare Worker Secret에 다음 값을 설정하세요.

```text
KAKAO_REST_API_KEY
NAVER_CLIENT_ID
NAVER_CLIENT_SECRET
```

카카오 키는 주소와 장소명 변환에 사용합니다. 네이버 두 값은 장소명 검색 보완에 사용하며, 네이버 지역 검색을 주소 변환기로 사용하지 않습니다. 기존 음식점·카페 검색도 네이버 설정을 사용합니다.

2026년 10월 5일 기준 카카오맵 무료 쿼터는 계정에서 처음 활성화한 앱에만 제공됩니다. 카카오 콘솔에서 해당 앱이 무료 대상인지 확인하세요. 무료 대상 앱은 주소 검색과 키워드 검색에 각각 일간 100,000회 쿼터를 받습니다. 무료 대상이 아니라면 유료 API를 자동으로 활성화하지 마세요. 실제 대상 여부와 한도는 [카카오맵 안내](https://developers.kakao.com/docs/ko/kakaomap/common)와 [쿼터 문서](https://developers.kakao.com/docs/ko/getting-started/quota)를 확인하세요.

공개 서버의 다이소MCP 앱은 무료 대상임을 확인한 뒤 활성화했습니다. 별도로 배포하는 경우 자신의 앱 설정을 확인해야 합니다.

## 조회 동작

- 도로명·지번주소는 카카오 주소 검색을 사용합니다.
- 역명·상호명은 카카오 키워드 검색을 사용하고, 네이버 지역 검색으로 보완합니다.
- 사용자가 위도·경도 또는 오피넷 KATEC 좌표를 입력하면 사용자 위치 변환을 건너뜁니다.
- 검색 결과의 좌표·지역·이름을 검증합니다. 극장·주유소의 좌표가 필요한 주변 검색에서 위치 변환에 실패하면 다른 지역의 기본 좌표로 대체하지 않고 오류를 반환합니다. 편의점의 원본 키워드 검색은 해당 서비스가 제공하는 검색 방식으로 이어갈 수 있습니다.
- CGV 주변 검색은 공식 극장 목록과 가까운 장소 후보를 대조한 뒤 거리순으로 정렬합니다.

위치 변환을 복구해도 원본 서비스의 인증 오류나 재고 조회 차단까지 해결되는 것은 아닙니다. 서비스별 헬스 체크를 함께 확인하세요.

롯데마트 지원은 중단했습니다. MCP 도구와 기본 도움말에서는 제외하며, 기존 REST 경로는 외부 요청 없이 `410 SERVICE_RETIRED`, 기존 CLI 명령은 지원 중단 오류를 반환합니다. 과거 호출 제한 통계와 분석 문서는 보존합니다.
