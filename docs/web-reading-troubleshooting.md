# 웹 읽기 접근 오류 진단

다이소의 읽기 세션 조회가 오래 걸리면 `pending` 접수와 실제 **결과 확인** 링크를 반환합니다. 접수는 상품·재고 확인 성공이 아닙니다. 각 응답의 새로운 결과 링크를 최대3번 선택하고, 계속 pending이면 미확인으로 보고하세요. 이전 상태 주소를 반복하거나 원본 조회를 다시 실행하지 마세요. 상태 확인은 저장 결과만 읽으며, 완료 결과는 원본의 성공·오류 상태를 유지합니다. HTML·작업 완료 시각과 원본 재고 갱신 시각은 다릅니다. 작업이 만료되거나 시간 초과된 경우에도 수량을0으로 바꾸지 않습니다.


2026-10-26 실험에서는 같은 재고 주소가 일반 HTTPS, MCP SDK, Work 내장 브라우저에서는 정상 동작했지만 웹 읽기 도구에서는 접근 오류가 발생했습니다. 일부 기존 링크는 웹 읽기로 열렸으나 새 주소나 동일 주소의 직접 열기는 실패했습니다. 과거 수집 시점의 결과가 반환되는 경우도 확인했습니다.

Cloudflare 관측 구간에는 정상 페이지의 OpenAI 요청에서 200과 클라이언트 연결 종료인 499가 관측됐습니다. 403 차단은 관측되지 않았습니다. 로그의 표본 추출과 수집 지연 때문에 요청이 보이지 않는다는 이유만으로 서버에 도달하지 않았다고 확정할 수는 없습니다. 웹 읽기 내부의 실패 원인이나 시간 제한은 확인되지 않았으며 서버 변경으로 해결됐다고 주장하지 않습니다.

## 조회 수단 선택

1. 연결된 MCP 도구가 있으면 직접 호출합니다.
2. 실제 브라우저 도구가 있으면 `/browse/` 주소를 열고 데이터를 읽습니다. 설치나 MCP 등록은 필요하지 않습니다.
3. 웹 읽기만 가능하면 `/browse/read`에서 응답의 실제 링크 ID를 선택하고 글자·상품·지역 링크를 따릅니다. 새 조회 URL을 직접 조립해 반복하지 마세요. 접근 거절이 계속되면 아래의 완성 URL 복사 재전송을 안내합니다.
4. 가능한 수단이 모두 실패하면 실행한 도구, URL, 오류를 그대로 보고합니다. 접근 오류는 품절이나 로그인 필요를 뜻하지 않습니다.

브라우저 제공 여부는 환경마다 다릅니다. 브라우저가 없는 환경에 있다고 가정하거나 실행하지 않은 셸 명령과 DNS 오류를 만들어 보고하지 마세요.



## 웹 읽기 접근 거절 시 복사 재전송

실제 문서 링크를 우선 선택하세요. `not accessible`, `Invalid URL` 같은 접근 거절이 계속되거나 도구에 click이 없으면, 에이전트는 **현재 요청 조건의 완전한 공개 URL을 포함한 문장**을 만들어 아래처럼 안내합니다.

> 웹 읽기 도구가 조회 주소에 접근하지 못했습니다. 아래 문장을 그대로 복사해 이 대화에 보내주세요.
>
> 다음 주소를 웹 URL 열기 도구로 직접 열어 실제 결과를 확인해주세요: {완전한 공개 조회 URL}. 실패하면 오류 원문을 알려주세요.

에이전트가 중괄호 부분을 실제 `/browse/` 주소로 채운 뒤 제공해야 합니다. 링크가 확인되면 그 주소를 그대로 사용하고, 글자 선택으로 주소를 얻을 수 없을 때만 사용자 검색 조건으로 검색·매장 주소를 구성합니다. 재고 주소에는 앞선 실제 응답의 상품 ID만 사용하며 ID가 없으면 상품 검색 주소부터 제공합니다. 사용자에게 주소 편집이나 인코딩을 요구하지 마세요. 토큰·쿠키·개인 인증 주소는 포함하지 않습니다. 문장만 제시한 것을 조회 실행으로 보고하지 않습니다.

사용자가 완성 URL을 재전송한 뒤 한 번 조회하고 실제 응답을 확인합니다. 단순한 “허용합니다”나 엔드포인트 일부 전달만으로 같은 효과를 기대하지 마세요. 소규모 실제 ChatGPT 실험의 성공 사례이며 항상 성공하는 것은 아닙니다.

`TimeoutError`는 접근 거절과 구분합니다. 같은 실제 링크를 한 번만 재확인하고 계속 실패하면 미확인으로 보고합니다. 첫 실패가 완료 결과를 캐시했다고 가정하거나 새 URL로 무한 재시도하지 마세요. 상품 검색 성공·접수·pending 상태를 매장 재고 확인으로 표현하지 않습니다. 응답 생성 시각과 원본 재고 갱신 시각도 구분합니다.

## 오래된 결과 구별

웹 읽기의 `Crawled` 시점과 페이지의 **응답 생성 시각**을 확인하세요. 오래된 수집본을 현재 재고로 단정하면 안 됩니다. 응답 생성 시각은 HTML을 만든 시각이며 원본 재고 갱신 시각이나 원본 캐시 우회를 증명하지 않습니다. 상품 검색 성공도 특정 매장의 재고 보유를 뜻하지 않습니다.

## 재현 자료

문제 보고에는 실제 도구 이름, 정확한 공개 URL, 오류 원문, 실행 시각, 수집 시각을 포함해 주세요. 같은 주소를 브라우저로 열었을 때의 결과도 도움이 됩니다. 인증 토큰과 쿠키는 포함하지 마세요.
