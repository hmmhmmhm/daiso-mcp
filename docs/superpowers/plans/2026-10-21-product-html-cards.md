# 웹 발견 설명과 상품 이미지 카드

사용자 승인: 검색 설명의 HTML GET 우선 안내, 버전·갱신일 표시, 실제 응답 이미지를 상품에 연결한 카드를 즉시 구현·배포한다.

1. 검색·버전·상품 카드의 회귀 검사를 먼저 추가하고 기존 응답에서 실패함을 확인한다.
2. 공통 안내 버전과 검색 설명을 첫 화면/llms/README에 표시한다. 상품 객체의 모든 원본 필드를 보존하면서 이름·이미지·식별값을 하나의 article로 묶는다. HTTPS의 인증정보 없는 imageUrl만 img에 사용하고 없거나 잘못된 URL은 이미지 없음으로 표시한다. JSON/MCP 계약은 변경하지 않는다.
3. 전체 check/coverage100/build/발견 자산 생성 및 독립 리뷰 후 PR 검사·병합배포한다. 공개 응답의 최신 버전/실제 이미지와 ID 연결/후속 링크 및 MCP10개를 검증한다.
4. GitHub 저장소 설명도 HTML GET 우선 문구로 갱신한다. 검색 엔진의 재수집·캐시 반영 시각이나 다른 Chat의 행동은 보장하지 않는다.
