# 문자 선택에서 실제 조회로 연결

목표는 가상 입력 성공을 실제 상품 조회 성공으로 확대하지 않고, 다음 실제 페이지까지 웹 도구가 이동 가능한지 확인하는 것입니다.

- 완료 화면에 현재 문자열을 URL 인코딩한 기존 운영 상품·매장 조회 링크만 추가합니다. 상품 응답은3개로 제한합니다.
- Worker의 외부 요청, 인증, 저장 범위는 변경하지 않습니다. 링크 선택 전에는 실제 조회가 수행되지 않음을 표시합니다.
- 실제 링크 생성 회귀를 먼저 실패시키고, 변경 후 기존 실험·타입·필수 검사와 독립 리뷰를 수행합니다.
- 배포 후 새 실행 또는 새 완료 주소에서 실제 상품 검색 링크를 클릭하고 상품 ID·이름을 확인합니다. 서버 도구 성공과 가상 데이터 성공을 구분합니다.
- 재고 조회는 상품·지역 선택과 추가 검증이 필요하며 이번 변경만으로 해결됐다고 보고하지 않습니다.

사전 근거: 링크만으로 `연필7` 및 `r9`를 만든 두 독립 실행에서 최종 requestId가 서버 로그와 일치했습니다. 전체 경과시간은 각각 약112초/81초였으나 Mac 실행·명령 지연이 함께 관측돼 웹 도구의 고정 지연으로 해석하지 않습니다.
