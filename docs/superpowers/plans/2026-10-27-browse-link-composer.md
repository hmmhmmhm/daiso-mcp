# 웹 읽기의 링크 선택으로 상품과 지역 입력

## 근거와 범위

PR335 실험에서 직접 open에 실패한 연필 검색 주소가 문자 링크 선택 뒤 실제 href click으로 성공했다. 상품58450 상세도 성공했다. 다음 병목은 재고 링크가 사용자 지역을 URL에 직접 추가하도록 안내하는 점이다. 고정 예제만 늘리지 않고 임의 검색어와 지역을 실제 링크 선택으로 전달한다.

연구 목표는 오후2시까지 계속 유지한다. 이 기능 배포만으로 모든 ChatGPT 계정이나 새 Chat 대화의 성공을 주장하지 않는다.

## 설계

- `/browse/compose/daiso/products/{입력}/{단계}`와 stores 경로에서 한글 초성·중성·완성형 및 영문·숫자·공백·하이픈을 링크로 선택한다. 최대32자. 빈 입력은 `~`.
- `/browse/compose/daiso/inventory/{상품ID}/{입력}/{단계}`는 선택한 실제 상품 ID를 유지하고 매장 지역을 입력한다. ID는 양의 정수 문자열만 허용한다.
- 각 단계에 기존 `/browse/` 실제 조회 링크를 제공한다. 상품·매장은 최대3개, 재고는 최대3개 매장. 입력 페이지는 API·주소검색·재고 원본을 호출하지 않는다. 사용자가 선택한 실제 조회에서만 기존 보호·캐시·오류 처리를 사용한다.
- 공개 MCP 도구10개, 기존 JSON API와 기존 browse 경로는 유지한다. 서버가 임의 외부 URL을 받아 프록시하지 않는다.
- 상품 HTML의 재고 링크를 지역 입력 페이지로 연결한다. /browse, 루트 발견 자산, 최신 버전 안내 및 README에서 링크 방식이 자연스럽게 발견되도록 연결한다. 사람이 보는 README 이미지와 구조는 유지한다.
- 웹 읽기는 응답에 있는 실제 링크 ID로 click하고 새 URL 문자열을 조립하지 않는다. 직접 open과 click의 차이를 명시한다. 원본 이미지 규칙·오류/품절/미확인 수량 구분을 유지한다.

## 검증 순서

1. 한글·영문 임의 입력과 상품 ID 보존, 부적절한 입력, 주입·경로 과다·최대 길이, 빈 검색 금지, 지우기/초기화, 상위 browse 처리와 원본 무호출 회귀를 먼저 실패시킨다.
2. 새 렌더러와 Hono 경로를 구현하고 상품 응답 링크를 갱신한다. 1워커 대상 검사와 타입·린트·커버리지 필수 검사, 직렬 리뷰를 수행한다. 운영 검증과 겹치지 않는다.
3. PR·CI를 통과한 뒤 배포한다. 생성 자산의 안내 버전과 실제 배포를 확인한다.
4. 웹 도구의 원시 open 실패 대조를 남기고 실제 링크 ID만 사용해 새 검색어→상품→임의 지역→실제 재고·진열 위치를 검증한다. 가상 데이터와 실제 결과, 응답 생성 시각과 원본 갱신 시각을 구분한다.
5. 독립된 두 번째 실행과 웹 커넥터 비교를 수행한다. 새 ChatGPT 대화의 UI 검증은 별도이며 브라우저 예산·세션 회수를 지킨다. 필요한 사용자 개입만 요청한다.

실험 Worker 코드는 기존 조건 비교를 위해 독립 유지한다. 운영 구현이 실험의 진단 데이터·공개 관측 저장소를 가져오지 않는다.
