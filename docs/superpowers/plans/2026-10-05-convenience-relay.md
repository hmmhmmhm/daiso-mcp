# 편의점 Mac 중계 복구 계획

사용자는 전체 복구와 현재 Mac 중계 사용을 승인했습니다. CU와 세븐일레븐은 Mac에서 상품·실재고가 성공하지만 Worker에서는 HTML/403 응답입니다. GS25는 상품 검색의 경로 장애와 재고 인증 부족이 별개입니다.

1. 기존 Dtryx 4320 서버에서 `/v1/convenience/` 경로를 별도 인증 토큰·호출 원장·동시성 제한을 가진 브라우저 없는 핸들러로 분배합니다. 기존 Tunnel/Access 호스트를 활용해 외부 URL 계약을 유지합니다. Dtryx/OY 예산은 공유하지 않습니다.
2. CU PocketCU 및 세븐일레븐 공식 API와 GS25 상품 검색/재고 조회의 고정 작업만 허용합니다. 임의 URL·헤더 프록시는 금지합니다. 요청·응답 크기, 전체 기한, 취소, 리다이렉트 차단, 인증 실패, upstream 비 JSON/실패 응답을 검증합니다. 정상 JSON은 기존 클라이언트가 해석하도록 전달합니다.
3. 공통 Worker 전송과 CONVENIENCE_RELAY_URL/TOKEN/ACCESS_CLIENT_ID/SECRET 바인딩을 REST 및 MCP 각 서비스에 연결합니다. 설정 없는 기존 동작은 유지합니다. 부분 설정은 명확한 오류로 처리하며 실패를 재고 0으로 변환하지 않습니다. GS25 인증키는 정상적인 공식 앱 사용 경로에서 확인할 수 있을 때만 사용하고 소스에 넣지 않습니다.
4. RED 재현 테스트 후 구현합니다. 기존 응답 계약을 유지하고 세븐일레븐 미확인 수량 -1을 품절로 표시하지 않습니다. 해당 표시의 정확성도 검증합니다.
5. 전체 check, coverage 4항목100%, build 및 독립 명세/품질 리뷰 후 PR을 생성합니다. 승인된 운영 복구 범위에서 Mac 런타임·토큰·Worker 설정을 반영하고 실제 상품명과 매장별 수량을 REST/MCP/게시 CLI로 검증합니다. 올리브영 PR208 냉간 준비 수정을 포함합니다.
6. GS25 재고 인증이 끝내 제공되지 않으면 상품 검색과 나머지 복구를 완료하되 GS25 재고는 미복구로 명시하고 필요한 인증만 요청합니다. 완료 판정은 성공 상태뿐 아니라 실제 수량 응답을 요구합니다.
