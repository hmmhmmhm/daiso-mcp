# 로컬 자원 보호 및 중계 복귀 계획

사용자 승인 범위: 메모리와 브라우저 과다 실행 방지, 로컬 CI 및 OY 감시 복귀.

1. 테스트·커버리지·CLI/MCP smoke를 공용 파일 잠금으로 직렬 실행한다. Mac 기본 워커는 1개, 다른 환경은 2개로 제한한다.
2. 시작 전과 실행 중 메모리 여유, CPU 합계, Chrome 본체 수를 관측한다. 시작 시 메모리 20% 미만, CPU 85% 초과, Chrome 본체 2개 초과면 실행을 거절한다. 실행 중 메모리 12% 미만 또는 Chrome 본체 2개 초과는 3회, CPU 90% 초과는 15회 연속 관측 시 소유 테스트 그룹만 종료한다. 2초 간격으로 관측하며 실패를 정상으로 처리하지 않는다.
3. 상태 수집 실패도 검사 실패로 처리한다. 사용자 브라우저, 운영 중계, 공용 Codex 프로세스는 종료하지 않는다. 새 종속성은 추가하지 않는다.
4. 저부하 Python 회귀로 잠금 충돌, 관측 실패, 임계값, 소유 자식 종료를 먼저 검증한다. 기존 Vitest 전체 회귀는 1워커로 한 번만 실행한다.
5. OY의 기존 단일 소유권·추가 페이지 종료·1GB RSS/30분/200요청 교체를 유지한다. CI 실행기, OY 중계, ready 확인, 감시·숨김 순으로 복귀한다. 안전한 상태와 실제 fresh 재고를 순차 검증한다.
6. AGENTS.md와 운영 문서에 브라우저 실험 1세션, finally 회수, 부하 중 작업 중단, 운영 검증과 테스트 직렬화를 명시한다.

플랫폼 공용 cua_node 누적은 프로젝트에서 임의 회수하지 않는다. 이 변경은 그 누수를 해결했다고 주장하지 않는다. 기존 미커밋 웹 실험은 별도로 보존한다.
