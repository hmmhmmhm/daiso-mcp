# 링크 선택으로 검색어 전달 실험

**목표:** 임의로 만든 URL의 open이 실패하지만 서버가 제공한 링크의 click은 성공하는 조건에서, 고정 예제에 없는 한글·영문·숫자 검색어를 전송할 수 있는지 검증합니다.

**구성:** 독립 가상 데이터 Worker에 `/compose/{run}/{text}/{stage}`를 추가합니다. 빈 입력은 `~`로 표시합니다. 한글은 초성·중성·종성을 실제 링크로 선택하며 영문·숫자·공백·하이픈도 링크로 추가합니다. 완료 링크는 입력한 문자열과 서버 생성 번호를 표시합니다. 실제 상품 API는 호출하지 않습니다.

**범위:** 32자 이하 한글 완성형, 영문 대소문자, 숫자, 공백, 하이픈. 모든 언어 또는 실제 상품 검색이 해결됐다는 주장은 하지 않습니다. 브라우저 입력 폼, JavaScript 실행, 임의 URL 이동 기능은 필요하지 않습니다. 기존 10개 MCP 도구 및 운영 경로는 변경하지 않습니다.

- [ ] 문서에 실제 존재하는 링크만 따라 예제에 없는 `연필7`을 완성하는 회귀 검사를 먼저 작성하고 실패를 확인합니다.
- [ ] 링크 생성 모듈과 Worker의 가상 결과·bounded 관측을 구현합니다. 입력 원문은 관측 로그에 저장하지 않습니다.
- [ ] 잘못된 인코딩·단계·초성/중성 범위·과도한 길이를 거절합니다. 마크업 삽입은 허용하지 않습니다.
- [ ] 원래 실험 및 새 회귀, 타입 검사, 저장소 필수 검사와 독립 리뷰 후 배포합니다.
- [ ] 두 개의 새 실행에서 실제 웹 도구 click만으로 한글·숫자 검색어를 완성하고 요청 번호를 서버 관측과 대조합니다. 호출 횟수와 소요시간도 기록합니다.
- [ ] 일반 ChatGPT 웹에서도 확인 가능한 경우 같은 실험을 수행합니다. Codex 웹 도구 성공만으로 Chat 제품 전체 성공으로 확대하지 않습니다.

선택 근거: 2026-10-27 도메인 비교에서 aka.page와 workers.dev 모두 raw open은 실패하고 실제 링크 click은 새 요청으로 성공했습니다. 임의 검색어가 웹 읽기 요청에 실리는지를 먼저 검증하며, 실제 상품 및 매장 조회 통합은 그 결과를 보고 진행합니다.
