# 최신 안내 발견 경로와 원본 이미지 표시

사용자 승인 범위: 최신 버전 안내의 자연스러운 발견과 원본 상품 이미지만 사용하도록 개선한다.

- /guide/latest는 현재 버전의 /guide/버전으로 임시 리다이렉트하며 캐시하지 않는다. 이전 버전 경로도 현재 버전으로 연결한다. 기존 llms/prompt/JSON/MCP 호환은 유지한다.
- README·첫화면·메타·robots·sitemap·공통프롬프트에서 현재 버전 안내를 연결한다. 첫 HTML 조회와 후속 상세 링크에 guide 버전을 전달하고 오래된 안내/결과를 최신으로 단정하지 않는다.
- 상품 카드에 동일 응답 imageUrl로 만든 복사 가능한 Markdown과 원본 링크를 함께 제공한다. 이미지 검색/image_query/검색 캐러셀로 대체하지 않으며, 원본 표시 불가시 링크나 텍스트만 제공한다.
- 안내/HTML은 새 캐시 저장을 막고 JSON과 원본 API 캐시는 유지한다. 외부 검색 캐시의 강제 삭제나 에이전트 판단을 보장하지 않는다.
- 회귀 red/green, 전체 check/coverage100/build/발견자산, 독립리뷰, GitHub검사·병합배포 후 실제 최신 안내·상품·후속 링크와 MCP10개를 검증한다.

추가 사용자 요청: 에이전트가 찾는 service-reference와 README/시작 안내/스킬의 터미널 호출 예제를 제거하고 WebFetch·URL 열기만 안내한다. 셸 우회 예제를 다시 노출하지 않는 회귀 검사를 유지한다. 서버의 MCP 전송 계약은 유지한다.
