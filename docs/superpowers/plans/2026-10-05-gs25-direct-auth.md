# GS25 정상 로그인 세션 직접 API 연결

사용자 승인: 운영 반영과 직접 API 인증. 네이버 정상 로그인으로 GS 토큰을 발급했고 실제 앱과 같은 코카콜라캔350ML(8801094017200) 재고16/7/10/0 및 토큰 갱신 후 재조회200을 확인했다. 가상기기를 재고 요청마다 실행하지 않는다.

1. 로컬 중계 전용 세션파일(0600)의 accessToken/refreshToken/deviceId를 읽는 전송기를 TDD로 구현한다. GS 고정 재고 URL에만 Bearer/appinfo를 적용하고 Worker/로그/응답에 토큰을 전달하지 않는다.
2. 만료1분 전 갱신, 동일 동시 갱신 공유, 인증거절 시1회 갱신·재조회, 원본/갱신의 취소와 기한, 갱신토큰 원자저장 및 실패시 재고0 위장 방지를 검증한다. 기존 API키 방식은 세션파일 미설정 때 유지한다.
3. GS25_AUTH_SESSION_FILE을 Mac 중계 시작 설정에 연결한다. 기존 용량/원장/조회캐시 정책을 유지한다. 별도 auth API를 외부에 노출하지 않는다.
4. 관련 테스트·전체check/coverage/build·독립 리뷰 후 PR 병합한다. 운영 파일 백업·중계 유휴 상태 확인 후 코드/세션파일 설정 적용, 원장 보존·실제 REST/MCP/CLI 재고 및 타서비스 smoke를 검증한다.

동일 상품·지역의 실재고가 앱과 일치하는 증거와 갱신 성공은 scratch의 private 인증 파일과 공개 검증 JSON에 분리되어 있다. 사용자 자격증명/회원정보/토큰은 커밋하지 않는다. 정상 refresh 만료 또는 계정 인증 철회 시 재로그인이 필요하며 오류로 전달한다.
