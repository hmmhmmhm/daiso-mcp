# 일본 다이소 구현 계획

> **For agentic workers:** Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** 일본 다이소 공식 상품·매장 조회를 별도 MCP/REST/CLI 서비스로 제공한다.

**Architecture:** 독립 `src/services/daisoJp` 클라이언트와 파서를 추가하고 기존 registry·routes·CLI 패턴에 연결한다. 매장 재고는 아직 지원하지 않으며 온라인 판매 가능 여부를 별도 필드로 유지한다.

**Tech Stack:** TypeScript, Hono, Zod, Vitest, Cloudflare Workers.

## 1. 원본 클라이언트와 파서

- [x] `tests/services/daisoJp`에 실제 HTML 구조 기반 정상·빈 검색·파싱 실패·입력 오류·상세 JSON 테스트를 먼저 작성하고 실패 확인.
- [x] `src/services/daisoJp/client.ts`, `parser.ts`, `types.ts`에서 공식 HTML 검색과 JSON 상세, JP/JPY 정보 구현. 외부 요청은 공용 fetchText/fetchJson의 timeout을 사용.
- [x] 상품 검색은 페이지당 원본 결과만 반환하고 매장 검색은 공식 검색 페이지를 사용. 실제 원본 HTML/JSON으로 검증.

## 2. MCP·REST·CLI 연결

- [x] MCP 도구와 REST/CLI 테스트를 먼저 작성해 실패 확인.
- [x] `src/services/daisoJp/index.ts`, `src/api/routes/daisoJpRoutes.ts`, `src/cli/commands/daisoJp.ts` 추가. `src/index.ts`, `registerServiceRoutes.ts`, `cli.ts`, CLI 도움말·옵션 정의에 등록.
- [x] 공개 안내와 전체 OpenAPI에 세 경로 및 `format=html` 예시 추가. 원본 오류를 502/503으로 표시하고 잘못된 입력은 400 처리.
