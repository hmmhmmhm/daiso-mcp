# 공개 MCP 도구 10개 통합

사용자 승인: 2026-10-21. 공개 MCP 도구는 정확히 10개이며 앞으로도 늘리지 않는다. 기능 확장은 기존 도구의 서비스/작업 선택지로 흡수한다. 기본 / 및 /mcp에 동일하게 적용한다.

공개 이름은 search_products, find_stores, check_inventory, get_product_details, find_places, get_showtimes, get_fuel_info, get_catalog, compare_products, submit_request이다. 기존 44개 도구는 deprecated 호출 별칭으로 보존하되 tools/list에는 노출하지 않는다. 목록에서 제외하는 것과 호출을 비활성화하는 것은 구분하며 기존 입력/응답 계약을 유지한다.

기존 서비스/클라이언트/인증/중계/REST/CLI는 재사용한다. 통합 도구는 service와 필요한 경우 operation으로 기존 핸들러를 고른다. 각 작업의 입력 스키마를 재사용하여 검증하며 지원하지 않는 조합/오타는 외부 요청 전에 거절한다. 목록 스키마는 JSON 입력을 명시하고 예시와 조건부 필수 인수를 설명한다. 새 submit_request는 범용 요청 이름과 확장 가능한 요청 구분을 제공하되 현재 실행 가능한 작업은 개발자 요청 제출뿐임을 명시한다. 알 수 없는 요청을 성공 처리하거나 임의 작업을 실행하지 않는다.

MCP 등록은 SDK 공개 API로 수행한다. 구형 별칭에도 기존 SDK 입력/출력 검증과 진단을 유지한다. deprecated 안내는 응답의 추가 메타정보로 전달하고 기존 content/structuredContent의 내용은 바꾸지 않는다. 목록은 명시적 고정 공개 이름만 포함하며 11번째 도구나 미매핑 신규 서비스 도구가 추가되면 검사를 실패시킨다.

회귀 검증: 44개 기존 작업이 모두 매핑되는지, 10개 목록과 이름/스키마가 정확한지, 실제 SDK tools/call로 새 이름과 구형 별칭이 동작하는지, 검증 오류/외부 오류/정상 품절/미확인 수량이 보존되는지 확인한다. 요청 제출 검증에는 가짜 저장소만 사용하고 운영 요청을 생성하지 않는다. REST/CLI와 공개 문서·스모크도 동기화한다. 전체 check/coverage100/build/독립 리뷰/CI/CodeQL을 거쳐 배포 후 / 및 /mcp 목록과 대표 새/구형 조회를 검증한다.
