# 운영 검사와 Mac 중계 재현성

사용자가 승인한 네 가지 개선을 기존 운영 구조 안에서 수행한다. 공개 MCP 도구는 정확히 10개이며 구형 호출과 JSON/HTML API 호환성을 유지한다.

1. 실제 공개 MCP 호출의 서비스 범위를 CLI와 일치시키고, 재고는 상품 존재만이 아니라 실제 매장 확인 여부를 검증한다. 기존 카탈로그와 상품명 재고 시나리오는 유지한다. 선택적 데이터 누락과 외부 실패를 숨기지 않는다.
2. GS 인증은 원본 재고 요청 없이 주기적으로 준비·정상 갱신하고 안전한 만료 시각·로그인 필요 상태를 인증된 health에 노출한다. 다른 중계와 터널은 loopback health 기반 감시로 장애 지속을 기록하고 프로세스가 죽은 경우 기존 launchd 복구를 활용한다. 불확실 소유 프로세스나 사용 중 프로세스를 추정 종료하지 않는다. 외부 알림은 이 대화의 사용자 개입 요청을 통해 처리하며 새로운 외부 메시지 경로는 만들지 않는다.
3. 이 Mac의 운영 설정을 재현할 수 있는 사용자 범위 관리 도구를 추가한다. 기존 전용 계정 설치기를 보존하며 자동 숨김 Swift 소스, 계획 출력, 상태 확인, 명시적 적용과 해제 방법을 제공한다. 기존 인증·환경·원장·터널 설정은 덮어쓰지 않는다. 새 Mac의 로그인 세션과 인증은 필요하다.
4. 기존 동일 요청 합치기·TTL 캐시를 유지한다. 일본 상세의 서로 다른 상품 동시 요청이 제한을 증폭하지 않도록 원본 진입을 직렬화하고 첫429 이후 대기를 모든 요청이 공유한다. 이미 대기 중인 요청도 원본 재시도 전에 제한을 확인한다. 메가박스 지연은 실제 기한 내 취소와 정확한 경고를 유지하며 검사 임계치를 완화하지 않는다.

각 기능은 실패 회귀 재현 후 구현하고 4지표100% 커버리지·필수검사·독립리뷰를 통과한다. GitHub 병합과 배포 뒤 필요한 Mac 파일만 정상 종료 확인 후 교체하고 실제 캐시 우회·MCP·CLI 응답으로 검증한다. 원본 제한의 영구 해소나 재부팅 실검증을 수행하지 않고 주장하지 않는다.
