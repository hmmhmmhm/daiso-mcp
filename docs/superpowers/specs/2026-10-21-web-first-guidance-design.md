# 무설치 에이전트 경로 선택 개선

사용자가 승인한 개선은 연결된 MCP 도구, 웹 읽기의 HTML GET, 두 수단이 없는 환경의 셸 순서로 첫 조회를 선택하는 것이다. 셸 DNS 실패를 웹 GET 실패로 확대하지 않고 실행하지 않은 요청의 성공·실패를 보고하지 않는다.

README 접힘 안내, 첫 화면, llms.txt, prompt, AI 지침과 클라이언트 안내를 맞춘다. 새 MCP 호출 예제는 공개 10개 도구를 사용하고 기존 별칭은 하위호환 레퍼런스로 구분한다. 상품 이미지는 해당 응답의 imageUrl만 쓰며 없거나 읽을 수 없으면 다른 상품·국가·웹 검색 이미지로 대체하지 않는다.

런타임 도구·REST JSON·하위호환은 변경하지 않는다. 실제 에이전트 판단을 문서만으로 강제할 수는 없으므로 안내 회귀 검사와 배포 응답 확인 후 별도 새 Chat 재현으로 평가한다.
