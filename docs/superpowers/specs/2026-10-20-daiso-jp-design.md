# 일본 다이소 지원 설계

사용자가 승인한 단계별 확장: 한국 다이소와 분리한 `daiso_jp` 서비스에 일본 상품·매장 검색을 먼저 추가한다. 공식 앱 재고 호출이 검증되기 전에는 매장 재고 조회 기능을 노출하지 않는다.

- 공식 온라인몰의 HTML 상품 검색을 이용한다. 공개 상품 JSON으로 상세 정보와 온라인 판매 가능 여부를 조회한다. 통화는 JPY, 국가는 JP다. 온라인 판매 가능 여부는 오프라인 재고가 아니며 수량을 생성하지 않는다.
- 공식 기업 사이트 `/shop/result?keyword=...`의 매장 검색 HTML에서 매장 코드·이름·주소·영업시간·공식 지도 좌표를 추출한다. 한국 지오코딩이나 유료 서비스를 사용하지 않는다. 지역·브랜드 범위와 페이지 범위를 응답에 명시한다.
- MCP: `daiso_jp_search_products`, `daiso_jp_get_product`, `daiso_jp_find_stores`. REST: `/api/daiso-jp/products`, `/api/daiso-jp/products/:id`, `/api/daiso-jp/stores`. CLI: `jp-products`, `jp-product`, `jp-stores`.
- 입력 길이와 페이지를 제한한다. 원본 오류·차단·파싱 변경을 빈 검색 결과와 구분한다. 정상 빈 검색은 원본의 정상 결과 마커가 있을 때만 허용한다. 요청 시간 제한과 기존 edge 캐시를 적용한다.
- REST의 기존 HTML 출력 미들웨어, 서비스 발견, OpenAPI 전체 명세, 사용 안내에 연결한다. 기존 한국 도구와 매장 재고 의미는 유지한다.
- 실제 원본 기반의 작은 fixture와 회귀 테스트로 정상·빈 검색·누락 필드·원본 차단·입력 오류·페이지 범위를 검증한다. 필수 검사와 100% 커버리지를 유지하고 HTTP/CLI/MCP를 실제 응답으로 점검한다.
