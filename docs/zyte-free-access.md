# Zyte 없이 조회하는 운영 정책

## 비용 정책

이 버전의 운영 서버는 Zyte Extract 요청을 보내지 않습니다. REST·MCP·운영 health의 공통 유료 전송 함수를 차단했고 유료 재시도와 응답 처리 코드를 제거했습니다. 기존 ZYTE_API_KEY가 남아 있어도 다시 활성화되지 않습니다. 다시 사용하려면 명시적인 코드 변경이 필요합니다.

`/health`의 `config.zyteApiKey.configured`는 키 보유 여부이며 `enabled: false`는 유료 호출 중지를 뜻합니다. 원본 무료 경로가 실패한 경우 오류 응답은 비용 정책에 따른 유료 대체 경로 중지를 안내합니다. 자동 재시도로 해결되는 오류로 표시하지 않습니다.

이 정책은 이 저장소의 서버 호출을 중지합니다. Zyte 계정의 구독 계약·월 약정이나 다른 프로그램에서 쓰는 키까지 취소하지는 않습니다. 계정 자체 비용은 대시보드에서 별도로 확인해야 합니다. 기존 지출 한도는 변경하지 않았습니다.

## 직접 조회와 확인된 제약

2026-09-15 검증 결과입니다.

| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 다이소·GS25 상품/매장·메가박스·롯데시네마 | 기존 직접 조회 경로를 유지합니다.                                                                                                                          |

| CU·디트릭스                               | 로컬 성공/Cloudflare 실패 차이가 남아 있습니다. CU 도메인 변경·디트릭스 포트 변경만으로 해결되지 않았습니다.                                               |
| 올리브영                                  | 일반 HTTP 요청은 403, 새 headed Chromium의 페이지 내 요청은 매장·상품·상품 식별자·재고 4개 API 모두 200 SUCCESS였습니다. headless Chromium은 차단됐습니다. |
| CGV                                       | 로컬 서명 HTTP 요청도 403입니다. 유료 fallback은 중지합니다.                                                                                               |

올리브영은 사용자 프로필·로그인 세션을 복사하지 않은 전용 브라우저로 검증했습니다. Mac 기반 중계는 창이 표시되는 브라우저와 로그인된 GUI 세션, 안정적인 전원·네트워크가 필요합니다. 다른 서버나 headless에서 동작한다고 가정하지 않습니다.

중계 실행·인증·바인딩 설정과 로컬 실측은 [올리브영 중계 가이드](oliveyoung-free-relay.md)에 있습니다. 현재 운영 연결은 상시 실행 장비 확인 후 별도로 적용해야 합니다.

롯데마트 지원은 중단했습니다. 기존 REST 경로는 외부 요청 없이 `410 SERVICE_RETIRED`를 반환합니다. 위치 변환은 [무료 위치 검색 가이드](free-location-search.md)를 확인하세요.

## 반복 조회 감소

세븐일레븐의 공개 상품·카탈로그·인기 검색어는 5분, 매장 검색은 30분 동안 서비스 계층에서 재사용합니다. REST와 MCP가 이 계층을 함께 쓰며 같은 키의 동시 조회는 합칩니다. 응답은 호출자마다 복제하고 성공 결과와 진행 중 조회는 각각 최대 128개 키만 보관합니다. 실패 결과는 캐시하지 않습니다.

실시간 재고는 이 새 캐시의 대상이 아닙니다. 메모리 캐시는 Worker 인스턴스별이므로 모든 지역의 전역 중복 제거를 보장하지는 않습니다. 기존 Edge Cache도 계속 적용됩니다.

## 운영 상태 해석

기본 health의 200은 개별 서비스의 정상 여부를 보장하지 않습니다. 유료 fallback을 끈 뒤 일부 health/smoke가 실패할 수 있으며 이를 정상으로 위장하지 않습니다. 비용 정책에 따른 조회 불가와 원본 장애를 함께 확인해야 합니다.
